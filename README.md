
# Lista Duplamente Encadeada em C

## Objetivo
Implementar uma lista duplamente encadeada utilizando a linguagem C.

## Funcionalidades
- Inserir elementos no início da lista.
- Inserir elementos em uma posição específica.
- Inserir elementos no final da lista.
- Remover elementos por posição.
- Buscar valores e retornar suas posições.
- Listar elementos e seus ponteiros anterior e próximo.

## Como compilar
gcc lista.c -o lista.exe

## Como executar
No terminal do Windows PowerShell:

.\lista.exe
